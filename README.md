# Шакал — браузерная версия v0.2

Чистый HTML/CSS/JS (ES-модули), без сервера и сборки. Логика — `src/game.js` (без DOM, пригодна для Capacitor/WebView), отрисовка — `src/ui.js`, картинки/иконки — одна карта `src/assets.js` (поле `img` для ассетов дизайнера).

## Запуск
ES-модули не грузятся с `file://`, нужен любой статический сервер:
`python3 -m http.server 8080` (или `npm start`) → http://localhost:8080
Тесты: `npm test` (node --test). Симуляция случайных партий: `npm run sim`.

## Новое в v0.2
- Режимы в интерфейсе — только 1 на 1: классика (у каждого 2 команды на противоположных сторонах, общий счёт; по умолчанию) и «1 на 1, по одному кораблю» (Белые против Чёрных). Режимы на 4 игроков остались в логике (`2v2`, `4p`), но скрыты.
- Картинки дизайнера из `assets/tiles` и `assets/pieces` (см. ASSETS.md), стрелки/пушка поворачиваются в коде, эмодзи — запасной вариант.
- Файловый мультиплеер: переключатель «Это устройство: оба игрока (hot-seat) / я играю за игрока 1 / 2». Чужими командами ходить нельзя (и в UI, и `applyMove(state, move, { asPlayer })`). Сохранение → файл `jackal-hod-N.json` → соперник загружает и ходит.
- Файл (формат v2): `version`, `seed`, `turn`, `current`, `moves` (журнал ходов), `log`, `pending`. `applyMove` — чистая функция (возвращает новое состояние).
- Стрелка с несколькими направлениями и конь: направление выбирается в тот же ход (тот же игрок делает продолжение, пират ждёт с монетой «в руках»).
- Крокодил возвращает на вертушку с сохранением шага.

## Реализовано
- Поле 11×11 без углов, 117 закрытых клеток, корабли в центрах сторон, по 3 пирата у 4 команд, 37 монет.
- Режимы: 2 игрока (по 2 команды на противоположных сторонах), 4 игрока 2 на 2 (союзники), 4 игрока каждый за себя. Hot-seat.
- Ходы: корабль вдоль своей стороны (только с пиратом на борту; давит вражеских пловцов, подбирает своих), высадка на клетку перед кораблём, возврат на свой/союзный корабль (прямо и по диагонали), ходьба на 8 соседей, открытие клеток, плавание вдоль берега, вражеский корабль = смерть, бой в воде = смерть.
- Монеты: по одной, только по открытым клеткам, нельзя бить с монетой, нельзя в крепость, в воде тонет, доставка на корабль = очко команды (в 2 на 2 — общий счёт).
- Удар: враги на клетке отправляются на свои корабли, груз остаётся.
- Клетки: пустые, стрелки 7 видов (случайный поворот), конь, вертушки 2–5 (бой только на том же шаге), лёд (повтор хода, в т.ч. конём), капкан (выручает союзник или бутылка рома), крокодил (назад в начало хода), людоед, крепость, крепость с аборигенкой (воскрешение по одному за ход, если живых < 3), сундуки I–V, самолёт (один раз, в любую клетку острова; можно ждать), воздушный шар, пушка, бочонок рома (пропуск хода), ром 1–3 (бутылки в запас команды).
- Цикл стрелок/льда → смерть. Конец игры: все монеты доставлены/утонули или ни у кого нет ходов. Победа по сумме монет.
- Сохранение/загрузка JSON (автосохранение в localStorage), ручные тестовые позиции — см. STATE_FORMAT.md и test-positions/.

## Упрощено / отложено
- Заменены пустыми клетками (16 шт.): пещеры (4), Бен Ганн, Пятница, миссионер, маяк, землетрясение, джунгли «нельзя сражаться» (3), трава (2), каррамба, сокровище галеона. Поэтому пустых 34 вместо 18.
- Монета на вертушке лежит на клетке, а не едет «в руках» (пират забирает её на выходе; теоретически её может подобрать союзник).
- Самолёт → лёд не даёт повторный полёт. Ром используется только для выхода из капкана. Нет режима на 3 игрока, нет проверки подлинности файлов (соперник может подправить JSON), нет ИИ, нет анимаций.
- Улёт за край поля (лёд/конь) — пират оказывается в ближайшей клетке моря.
